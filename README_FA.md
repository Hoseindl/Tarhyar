# طرح‌یار آفلاین — بازطراحی حرفه‌ای نسخه ۳ آزمایشی

این پروژه **سورس اندروید** است، نه APK کامپایل‌شده. منوی کشویی واقعی، طراحی روشن با رنگ‌های زنده، آیکون نصب موجود، فرم اطلاعات معلم، خواندن PDF متنی به‌صورت آفلاین، نمایش پیشرفت و حجم فایل و تولید سه قالب متفاوت پیاده‌سازی شده‌اند.

## نکات مهم کیفیت آموزشی
- طرح **روزانه** فقط یک موضوع انتخاب‌شده را با مراحل و زمان‌بندی یک جلسه تولید می‌کند.
- طرح **ماهانه** موضوعات را در جلسات ماه توزیع می‌کند.
- طرح **سالانه** از مهر تا خرداد به سه جدول تقسیم می‌شود و سهم موضوعات با وزن تعیین‌شده توسط معلم توزیع می‌شود. ورودی «جلسات قابل تدریس در سال» باید با تقویم واقعی مدرسه اصلاح شود.
- پیشنهاد ساحت‌ها بر اساس **عنوان سرفصل و قواعد** است؛ برنامه بدون مدل زبانی آفلاین نمی‌تواند محتوای هر کتاب دلخواه را عمیقاً بفهمد. هر ساحت دارای مصداق اجرایی است و باید بازبینی شود.
- این فرم‌ها برگرفته از اجزای رایج طرح درس‌اند؛ **ادعای تأیید رسمی وزارت آموزش‌وپرورش ندارند**.
- PDF اسکن‌شده بدون متن OCR نمی‌شود. خروجی Word یک HTML با پسوند DOC است، نه DOCX واقعی. PDF از طریق چاپ سیستم اندروید ذخیره می‌شود.

## ساخت APK
تمام محتوای پوشه را به مخزن **خصوصی** GitHub منتقل کنید و `.github/workflows/build-android.yml` را حفظ کنید. در Actions، گردش‌کار Build Tarhyar Android APK را اجرا کنید. فایل `app-debug.apk` در Artifact به نام Tarhyar-Offline-Installable-APK قرار می‌گیرد؛ APK آزمایشی امضاشده است.

## حریم خصوصی
مجوز INTERNET در Manifest وجود ندارد. فایل PDF در حافظه موقت پردازش می‌شود و به سرور ارسال نمی‌شود.

## وضعیت بررسی
ساختار فایل‌ها و کد JS باید پیش از توزیع گسترده با PDF واقعی روی چند گوشی آزموده شوند. APK در این محیط ساخته نشده است.
