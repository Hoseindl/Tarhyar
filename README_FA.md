# طرح‌یار آفلاین — نسخه ۲.۰ (سورس اندروید)

این پروژه یک اپ آفلاین برای تولید جدول طرح درس از PDF متنی است. **APK آماده نیست** و باید در GitHub Actions یا Android Studio کامپایل شود.

## قابلیت‌ها
- انتخاب PDF، نمایش نام و حجم فایل، درصد انتقال فایل به برنامه و تعداد صفحات/عنوان‌های استخراج‌شده
- سه نوع طرح روزانه، ماهانه و سالانه؛ سالانه در جدول‌های مهر تا دی، بهمن تا اردیبهشت و خرداد
- جدول اطلاعات معلم/مدرسه/مدیر و جدول‌های آموزشی، با امکان ویرایش سلول‌ها
- ساحت‌های شش‌گانه در جدول پوشش و انتخاب قاعده‌محور ساحت مرتبط با هر موضوع
- ذخیره HTML، فایل DOC سازگار با Word (HTML در قالب DOC)، و PDF با منوی Print/Save as PDF اندروید
- آیکون اختصاصی برنامه در پوشه‌های mipmap
- صفحه درباره سازنده: حسین دالوند، هنرآموز شبکه و نرم‌افزار رایانه، لرستان، @Teach_future

## ساخت APK
محتوای این پوشه را در مخزن خصوصی GitHub قرار دهید (پوشه `.github` نیز باید آپلود شود). در تب Actions گردش‌کار `Build Tarhyar Android APK` را اجرا کنید. پس از موفقیت، artifact به نام `Tarhyar-Offline-Installable-APK` را دانلود کنید و `app-debug.apk` را نصب کنید. APK آزمایشی با کلید debug امضا می‌شود و برای انتشار بلندمدت مناسب نیست.

## محدودیت‌های صریح
- موتور قواعد آفلاین **هوش مصنوعی مولد نیست** و نمی‌تواند فهم کامل محتوای همه کتاب‌ها را تضمین کند.
- PDF اسکن‌شده بدون لایه متنی پشتیبانی نمی‌شود؛ OCR در این نسخه موجود نیست.
- موضوعات و ساحت‌ها باید توسط معلم بررسی شوند؛ تقویم و تعداد جلسات تخمینی است.
- DOC خروجی یک سند HTML با پسوند DOC است، نه فایل DOCX واقعی؛ ممکن است برنامه‌های مختلف سازگاری متفاوت داشته باشند.
- برنامه هنوز در این محیط کامپایل و روی گوشی تست نشده است. هشدار نصب بسته به Play Protect و وضعیت دستگاه ممکن است وجود داشته باشد.
- درصد پیشرفت نشان‌دهنده خواندن بایت‌های فایل PDF است، نه کیفیت تحلیل متن.
- نسخه سبک روی گوشی‌های کم‌حافظه با کتاب‌های بسیار حجیم ممکن است کند باشد.

## حریم خصوصی
هیچ مجوز اینترنت در Manifest درخواست نشده است. فایل PDF به حافظه موقت برنامه منتقل و پس از استخراج متن حذف می‌شود؛ اطلاعات فرم در این نسخه به سرور ارسال نمی‌شوند.
