# طرح‌یار آفلاین — سورس نسخه ۱ اندروید

این پروژه یک اپ اندرویدی آفلاین برای انتخاب PDF متنی، استخراج متن با PDFBox-Android، پیشنهاد عنوان درس، ساخت جدول طرح روزانه، ماهانه و سالانه، ویرایش جدول و خروجی HTML یا چاپ به PDF است.

## ساخت APK
محتوای این پوشه را در مخزن **Private** در GitHub آپلود کنید. فایل `.github/workflows/build-android.yml` باید وجود داشته باشد. از Actions > Build Tarhyar APK > Run workflow استفاده کنید. بعد از موفقیت، Artifact به نام `Tarhyar-Offline-APK` شامل `app-debug.apk` امضاشده آزمایشی خواهد بود.

## محدودیت‌های واقعی
- APK در این محیط ساخته یا روی گوشی آزمایش نشده است.
- کتاب‌های اسکن‌شده OCR ندارند؛ باید PDF متن‌دار انتخاب شود یا عنوان‌ها دستی وارد شوند.
- شناسایی عنوان‌ها با قواعد متنی انجام می‌شود و ممکن است ناقص باشد.
- ساحت‌ها به شکل پیشنهادی بر اساس واژگان موضوع اختصاص داده می‌شوند و باید بررسی شوند.
- برای ماهانه چهار هفته و سالانه ۳۶ هفته در نظر گرفته شده؛ تعطیلات لحاظ نشده‌اند.
- PDF با سرویس چاپ اندروید ذخیره می‌شود؛ برای ذخیره فایل PDF گزینه Save as PDF را در پنجره چاپ انتخاب کنید.
- اپ مجوز INTERNET ندارد و هیچ اطلاعاتی را ارسال نمی‌کند. وابستگی PDFBox فقط هنگام ساخت APK از Maven دریافت می‌شود.
- نسخه Release امضاشده با کلید اختصاصی برای انتشار عمومی باید جداگانه تنظیم شود.
